初めての申込みでも迷わないLP設計

一言コメント

初めてクレジットカードを作る学生が不安なく申し込みまで進めるよう、情報の順序と読みやすさを重視して構成設計から制作しました。

制作概要

・案件種別：クレジットカード申込LP（自主制作／想定案件）
・想定クライアント：株式会社エムエス銀行「MSカード」
・制作目的：学生層へのクレジットカード申込促進
・制作範囲：縦長LP（1ページ完結型）

URL

GitHub Pages（lp-mscard）

担当

構成設計／デザイン／コーディング

制作背景・要件

18歳以上の学生を対象に、「初めてのクレジットカード選びが不安」「どのカードを選べばよいかわからない」という心理的ハードルを下げることを目的に制作しました。
高校生を除く学生層を想定し、クレジットカードに関する知識がなくても、内容を読み進めるだけでサービス理解から申込まで迷わず進めることを要件としています。
また、キャンペーン訴求と申込導線を両立させ、離脱を防ぐ構成であることを条件としました。

構成設計・画面設計で意識した点

ファーストビューでは「学生向け」「初めてでも安心」というメッセージを明確に打ち出し、対象者を即座に絞り込む構成としています。
ページ全体は「カードの特徴理解 → 利用イメージ → キャンペーン訴求 → 申込方法」という流れで設計し、上から順に読むことで自然に行動へつながる構成としました。
CTAは画面下に追従配置し、各セクション下にも設置することで、検討段階に応じていつでも申込みに進める導線を意識しています。
情報量が多くなりやすいLPのため、セクションごとの役割を明確にし、視線の流れが滞らない画面設計を行いました。

デザインの判断

学生向けカードとしての「安心感」「親しみやすさ」を重視し、明るくやわらかい配色を基調としたデザインとしました。
イラストと写真を併用することで、堅くなりすぎず、金融サービスでありながら心理的な距離を感じさせないトーンを意識しています。
また、キャンペーン情報は背景色を切り替えて視覚的に強調し、訴求ポイントが埋もれないよう整理しました。

実装・制作工程

構成設計を行った上でデザインを作成し、HTML / CSSで縦長LPとして実装しました。
コンテンツ単位でセクションを分け、今後の情報差し替えやキャンペーン変更にも対応しやすい構造を意識しています。
視認性や可読性を損なわないよう、余白・文字サイズ・行間を調整し、長時間スクロールしても読み疲れしにくい実装を行いました。

制作範囲・制約

・対応デバイス：PCのみ（構造設計と画面設計の検討を優先し、レスポンシブ対応は未実装）
・自主制作のため、実際のクライアントや数値検証は行っていません
