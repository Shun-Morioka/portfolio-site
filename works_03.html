未経験者の不安を下げる採用サイト設計

一言コメント

未経験の新卒・中途が「ここなら挑戦できそう」と感じられるよう、採用メッセージと情報導線を整理した採用サイトを制作しました。

制作概要

・案件種別：不動産会社 採用サイト（自主制作／想定案件）
・想定クライアント：株式会社ハートリンク不動産
・制作目的：未経験人材への採用訴求と企業理解の促進
・制作範囲：採用サイト TOPページ（目次構造）

URL

GitHub Pages（recruit-heartlink）

担当

構成設計／デザイン／コーディング

制作背景・要件

未経験の新卒・中途人材に向けて、「不動産業界はハードルが高そう」「自分にできるか不安」といった心理的障壁を下げることを目的に設定しました。
短い閲覧時間でも会社の雰囲気や考え方が伝わり、「まずは話を聞いてみたい」と感じてもらえることを要件としています。
また、制作時間が限られている想定のため、情報量を抑えつつも全体像が把握できる構成とし、TOPページから各コンテンツへ遷移できる採用導線を設計条件としました。

構成設計・画面設計で意識した点

採用サイト全体を「仕事を知る」「人を知る」「キャリアを知る」「採用情報」という役割ごとの目次構造で整理し、求職者が自分の関心に応じて情報を選択できる設計としています。
TOPページのみで構成することで、ページ遷移の負担を減らし、短時間でも企業理解が進む導線を意識しました。
また、未経験者でも仕事内容やキャリアイメージを掴みやすいよう、説明的になりすぎない見出し設計を行っています。

デザインの判断

未経験者に安心感と前向きな印象を与えるため、「誠実」「爽やか」「挑戦」をキーワードにデザインを設計しました。
青を基調とした配色と余白を活かしたレイアウトにより、堅すぎず軽すぎないトーンを意識しています。
人物写真を大きく使用することで、会社の雰囲気や人柄が直感的に伝わるよう配慮し、採用サイトとしての親しみやすさを重視しました。

実装・制作工程

構成設計と画面設計を先行し、全体の情報整理を行った上でデザインを作成し、HTML / CSSで実装しました。
将来的に下層ページを追加できることを想定し、ナビゲーションやセクション構造は拡張しやすい設計としています。

制作範囲・制約

・対応デバイス：PCのみ（構造設計と画面設計の検討を優先し、レスポンシブ対応は未実装）
・自主制作のため、実際のクライアントや数値検証は行っていません
・TOPページのみ制作（目次型構成）
