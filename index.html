SKILL

HTML/CSS3

HTMLの基本構文を正確に理解し、適切なマークアップが可能です。 CSSではレスポンシブ対応を行い、デバイスごとに最適化されたレイアウトを構築できます。 また、セマンティックHTMLを用いたアクセシビリティを意識したコーディングを行っています。

jquery

Webサイトに簡単な動きを付けるためのライブラリとして使用可能です。 Lightbox2、bxSliderなどを用いたUI演出の実装経験があります。

JavaScript

基本的な文法と挙動を理解しており、UI/UX向上を目的とした実装が可能です。 動的な表示切り替えやユーザー操作に応じた処理を行っています。

WordPress

基本操作を理解しており、既存テーマの調整や更新・運用を想定した実装が可能です。

Photoshop

画像のレタッチ、トリミング、色調補正などの画像加工を中心に使用しています。 バナー制作やWebサイトで使用するビジュアル素材の作成を行っています。

Illustrator

図形作成や地図デザインなどの基本操作が可能です。 ロゴマーク・ロゴタイプの制作経験があり、ブランドデザインに関わる制作を行った経験があります。

XD

デザインカンプの作成経験があります。 UI/UXを意識した画面構成やレイアウト設計が可能です。

Figma

Webサイトのデザインカンプ作成をメインに使用しています。 構成設計を踏まえた画面設計に加え、バナーやビジュアル制作も行っています。

Canva

基本的な操作に加え、バナーなどの簡易的なデザイン制作に使用しています。 用途や訴求内容に応じて、文字組みや情報量を調整したレイアウト作成が可能です。

GitHub

Webサイト更新時の履歴管理を目的として利用しており、変更内容の管理や差分確認を行っています。 複数ファイルの修正や更新作業において、作業履歴を残しながら安全に運用しています。
